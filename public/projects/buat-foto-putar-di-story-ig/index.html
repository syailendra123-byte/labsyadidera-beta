1. Fungsi Web Ini

Website ini pada dasarnya adalah sebuah alat Manipulator EXIF (Exchangeable Image File Format) yang bekerja secara spesifik dan efisien. Fokus utama dari web ini bukanlah mengedit visual gambar, melainkan mengubah identitas "di balik layar" dari gambar tersebut.

Secara detail, fungsi utama web ini adalah:

  • Spoofing Perangkat (Device Spoofing): Mengganti informasi pabrikan (Make) dan model perangkat (Model) pada metadata foto asli menjadi data spesifik milik kacamata Ray-Ban Meta.
  • Membuka Fitur Tersembunyi di Instagram: Aplikasi Instagram memiliki fitur eksklusif untuk foto yang diunggah dari kacamata pintar Ray-Ban, yaitu kemampuan untuk diputar (rotasi/efek khusus) saat dijadikan Instagram Story. Dengan menggunakan web ini, foto dari kamera apa pun (DSLR, Android, mirrorless) dapat diputar di Story seolah-olah diambil menggunakan Ray-Ban.
  • Optimalisasi Khusus iOS: Saat ini, bypass algoritma pembacaan EXIF Instagram untuk fitur rotasi Ray-Ban ini terbukti berhasil dieksekusi secara sempurna melalui aplikasi Instagram di perangkat iPhone (iOS). Ketika menggunakan perangkat Android, ini tidak berhasil.

2. Cara Kerja

Proses kerja dari website ini memadukan manipulasi data sisi klien (client-side) atau server-side dengan pemahaman tentang bagaimana platform sosial media membaca file media. Berikut adalah rincian teknis cara kerjanya:

A. Tahap Pembacaan (Parsing)

  1. Pengunggahan Gambar: Pengguna mengunggah gambar (biasanya berformat JPG/JPEG yang mendukung EXIF data secara native) ke dalam website.
  2. Ekstraksi EXIF: Skrip pada web (menggunakan library pemrosesan gambar/EXIF) akan membongkar susunan data biner dari gambar tersebut untuk menemukan blok data EXIF. Blok ini berisi informasi kapan foto diambil, ISO, lensa, hingga merk kamera.

B. Tahap Modifikasi (Spoofing)

  1. Injeksi Tag Spesifik: Web secara otomatis akan mencari tag Make (ID: 0x010F) dan Model (ID: 0x0110).
    • Nilai Make yang lama akan dihapus dan ditimpa dengan string baru, yaitu: "Meta AI"
    • Nilai Model akan ditimpa dengan string yang sangat spesifik, yaitu: "Ray-Ban Meta Smart Glasses"
  2. Penyusunan Ulang Biner (Re-encoding): Setelah metadata dimodifikasi, web akan menyatukan kembali blok EXIF yang baru dengan blok piksel gambar asli. Proses ini dilakukan tanpa mengurangi kualitas gambar (lossless) karena piksel visual tidak disentuh sama sekali.

C. Tahap Eksekusi di Instagram

  1. Pengunduhan & Publikasi: Pengguna mengunduh gambar hasil modifikasi ke iPhone mereka.
  2. Validasi Sistem iOS Instagram: Ketika gambar ini dipilih untuk diunggah ke Instagram Story melalui iPhone, algoritma Instagram iOS akan memindai EXIF. Karena ia mendeteksi tag "Make: Meta" dan "Model: Ray-Ban", aplikasi langsung memberikan "izin" (trigger) untuk memunculkan antarmuka rotasi/efek 360 yang secara default dikunci untuk perangkat biasa.
